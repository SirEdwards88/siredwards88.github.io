# Sir Edwards — raíz del dominio

Este repositorio publica `https://siredwards88.github.io/` y sirve de soporte a la verificación Android de Sir Edwards Quiz.

- El juego permanece en `https://siredwards88.github.io/sir-edwards-quiz/` (otro repositorio).
- La futura asociación Android se publicará en `/.well-known/assetlinks.json` **solo después** de disponer del nombre de paquete y de la huella SHA-256 reales de la firma.
- No subir aquí claves privadas, contraseñas, keystores ni datos personales.
- La activación de GitHub Pages debe comprobarse en Settings → Pages; este repositorio por sí solo no confirma que el sitio esté publicado.
